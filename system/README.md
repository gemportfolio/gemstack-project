# GemStack Official Project Site

GemStack's first official marketing site: a conversion-focused community + waitlist site.

## Current positioning

**GemStack — Conversion systems for modern brands.**

The current product is the done-for-you Personal Brand / Business Conversion System.
The future product is a platform that lets users create, manage and grow those systems themselves.

## Structure

- `index.html` — main landing page
- `css/styles.css` — styles and responsive layout
- `js/main.js` — interactions
- `assets/` — future images, logos and other assets
